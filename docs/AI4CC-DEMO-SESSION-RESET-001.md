# AI4CC-DEMO-SESSION-RESET-001

Owner-authorized behavior: when a visitor enters the Live Demo from the homepage Demo CTA, the demo view starts a fresh browser demo session and does not render data from the previous demo test. Historical interaction/lead records are preserved in the system of record; only public demo rendering is reset. The new call can be shown after a manual page refresh. No heartbeat, background polling, or realtime subscription is introduced.
