# G04 - Leads

For: managers and agents at {{business_name}}. Page: **Lead Management**.

A lead is created automatically when a call ends with enough information (name, a way to reach them, and why they called).

## Read the page
- **Summary tiles:** Total Leads, Open, Opportunities, Follow-Up, Converted, Pipeline Value.
- **Filters:** search box, **All stages**, **All priorities**, and **All ownership** (Assigned to me / Unassigned). The count "N shown" updates as you filter.
- **Pipeline list (left):** each lead with name, stage, priority, owner and follow-up date. Select one to open it on the right.
- **Refresh:** press **Refresh Leads** for the latest. The page shows "Last refreshed".

## Work a lead
1. Select the lead. Read its summary strip: Priority, Assigned Agent, Next Action, Next Follow-Up, Value / Probability.
2. Under **Operational Lifecycle**, set **Assigned Agent**, **Pipeline Stage**, **Priority**, **Lead Score**, **Next Action** and **Next Follow-Up**. Managers can also set **Estimated Value**, **Probability %** and **Expected Close Date**.
3. Select **Save Changes**. Each change is recorded on the lead's history.
4. Select **Activity + Tasks** to log calls and create follow-up tasks (G05).

## Stages
new, qualified, contacted, follow up, opportunity, nurture, converted (won), lost.

## Closing a lead (managers)
- **Convert / Won:** select the button and confirm. This is final.
- **Mark Lost:** type a **Required lost reason**, then select **Mark Lost** and confirm.
- Owners, admins and supervisors can close leads. Others see "Terminal disposition is not available".

## What each role can edit
Owner, admin, supervisor: everything. Operator: open leads. Agent: leads assigned to them (not commercial fields). Viewer: read-only ("This Lead is read-only for your current role").

**If something looks wrong:** if a lead is missing, press **Refresh Leads**. If the fields are greyed out, check your role (shown at the top right of the page) and ask {{support_email}}.
