# G07 - Voicemails

For: the front desk at {{business_name}}. Page: **Voicemails** (title "Voicemail Inbox").

## Check for messages
1. Open **Voicemails**. Nothing loads by itself: the page says no query has been run.
2. Select **Check Voicemail**. The page shows "Last checked" with the time.
3. Messages appear on the left with caller, status and time. Select one.

## Read and listen
The message shows the caller, time and length, plus **Reason**, **Status**, **Destination** and the recording ID. **Transcript** shows the text of the message ("Transcription pending..." means it is still being written). If a recording is available you can play it in **Recording**.

## Work a message
| Button | Use it to |
|---|---|
| Open Interaction | See the call in Agent Workspace |
| Mark Reviewed | Show you have seen it |
| Callback Pending | Show someone still needs to call back |
| Resolve | Close it out |

Statuses are shared with your team, so keep them current.

## Good habits
- Check voicemail at the start and end of each business day.
- After you call back, log it on the lead (G05).

**If something looks wrong:** if a message you expect is missing, select **Check Voicemail** again. If a transcript stays pending for a long time, or there is no recording, email {{support_email}} with the caller's number and time.
